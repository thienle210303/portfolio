# .hallmark

This folder's presence turns on Hallmark's edit-time lint for `.tsx` files
(its hook only lints components inside a project with a `.hallmark` folder).
Hallmark also writes its working files here (pre-flight cache, audit records,
screenshots); those are git-ignored. How Hallmark is used on this site:
[`.claude/skills/the-pass/SKILL.md`](../.claude/skills/the-pass/SKILL.md).

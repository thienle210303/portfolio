In Vietnam Thien's name is Lê Nguyễn Minh Thiện. In the US the order got swapped to Nguyen Le Minh Thien, so official papers (Forage certificates and others) read "Nguyen MT Le" or "Nguyen Le". Those are his, not someone else's, and not an error to fix. The site uses "Thien Le" and the seal "Thiện Lê".

**How to apply:** never flag these names as a mismatch, and never "correct" them on a certificate image. Related: [[round-20-redesign]].
